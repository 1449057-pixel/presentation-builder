# Детектор компетенций (Competency Detector)
## Геймифицированные HR-презентации и оценка компетенций

### 📌 Описание проекта
Веб-сервис для интерактивного проведения HR-ассессментов, тренингов и оценки компетенций кандидатов/сотрудников. Включает в себя:
- Режим презентатора / геймифицированного прохождения (`PlayerMode`) с поддержкой полноэкранного показа (F11/Fullscreen) без пустых полей.
- Интерактивный Drag & Drop для распределения вопросов по компетенциям с кнопками дублирования вопросов и возврата карточек в пул.
- Оценку кейсов кандидатов с сопоставлением с эталонным профилем.
- Конструктор интерактивных слайдов (`PresentationBuilder`) с поддержкой импорта презентаций из PDF-страниц и изображений.
- Банк слайдов и шаблонов (`SlideBankModal`).
- Ролевую модель: Администратор (`/admin`) и Ведущий/Тренер (`/user` - режим только запуска).
- Встроенное локальное файловое хранилище базы данных `data/db.json`.

---

### 🚀 Стек технологий
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React, Motion, pdfjs-dist
- **Backend / Server**: Node.js, Express, Vite middleware mode
- **Сборщик**: Vite + esbuild для серверного бандла

---

### 💻 Инструкция по локальному запуску

#### 1. Установка зависимостей
```bash
npm install
# или
bun install
```

#### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сервис запустится по адресу: `http://localhost:3000`

#### 3. Сборка для продакшна
```bash
npm run build
```
Сборка генерирует клиентскую статику в папку `dist/` и бандлит сервер в `dist/server.cjs`.

#### 4. Запуск собранного проекта
```bash
npm start
```

### 📂 Структура проекта
```
├── server.ts             # Express-бэкенд, маршруты API, раздача файлов и статики
├── data/
│   └── db.json           # Локальная база данных (пользователи, презентации, банк слайдов)
├── public/
│   └── downloads/        # Архивы проекта
├── src/
│   ├── App.tsx           # Главный компонент маршрутизации
│   ├── main.tsx          # Точка входа React
│   ├── types.ts          # TypeScript интерфейсы и типы
│   ├── context/
│   │   └── AuthContext.tsx  # Контекст авторизации и ролевого доступа
│   ├── lib/
│   │   └── api.ts        # Клиентские вызовы API
│   ├── utils/
│   │   └── pdfExtractor.ts # Извлечение слайдов из загруженных PDF файлов
│   └── components/
│       ├── PresentationDashboard.tsx # Главный дашборд презентаций
│       ├── PresentationBuilder.tsx   # Редактор презентации
│       ├── PlayerMode.tsx            # Интерактивный полноэкранный плеер
│       ├── AccessLinksModal.tsx      # Модальное окно ссылок и выгрузки файлов
│       ├── SlideBankModal.tsx        # Библиотека готовых слайдов
│       └── editors/                  # Редакторы типов слайдов (DragDrop, Definitions, Quiz, Static)
```
